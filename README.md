## Featured projects

- **[TuneFlow AI](https://github.com/madan-kumar07/Tuneflow-ai)** — A React music player for discovering tracks and managing a song library. A Spring Boot API handles search and authentication, and PostgreSQL stores the catalogue.
- **[Smart Canteen](https://github.com/madan-kumar07/canteen-project)** — A food pre-ordering app that lets students order ahead and canteen staff track incoming orders. It uses React, Flask and Socket.IO for live updates.

## Run locally

The portfolio uses React, TypeScript and Vite, with Three.js for the interactive introduction. From the repository root, run these commands with Node.js 20 or newer installed.

```sh
npm ci
npm run dev
```

To check the production version locally, run `npm run build`, then `npm run preview`.
